# نظرسنجی هیئت شهدای مدافع حرم اهل‌بیت

نسخهٔ نهایی فرم یک‌صفحه‌ای مراسم پنج‌روزه، گردان ۱۳ امام حسین علیه‌السلام؛ رابط فارسی و راست‌به‌چپ، بک‌اند Node.js، ذخیره‌سازی SQLite، پنل مدیریت و خروجی واقعی Excel.

برای تحویل سریع به برنامه‌نویس، ابتدا `HANDOFF.md` را بخوانید؛ محل داده‌ها، ستون‌های خروجی و مراحل پذیرش نصب در آن مشخص است.

عبارت آغاز فرم: «السلام علیک یا فاطمه الزهرا سلام الله علیها». نام و شماره تماس در ابتدای فرم و اختیاری هستند. شماره در صورت ورود باید یازده رقم و با `09` شروع شود؛ جای‌نگهدار آن `09101679458` است. ارقام فارسی و عربی هم پذیرفته و به ارقام لاتین تبدیل می‌شوند.

## اجرای سریع با Docker روی Ubuntu

برای راه‌اندازی تعاملی Docker، Nginx، گواهی و حساب مدیر پس از کلون، [راهنمای DevOps](DEVOPS.md) را دنبال کنید و `bash deploy/install.sh` را اجرا کنید. مراحل زیر برای نصب دستی هستند.

این پروژه مستقل اجرا می‌شود. پورت پیش‌فرض میزبان `7480` و پورت داخلی کانتینر `3000` است. Node.js مناسب داخل تصویر Docker قرار دارد.

۱. پوشهٔ پروژه را روی سرور قرار دهید و وارد همان پوشه شوید.

۲. نام کاربری و رمز مدیر را تعیین کنید. رمز هنگام تایپ نمایش داده نمی‌شود.

```bash
npm run setup
```

این دستور فقط هش scrypt رمز و secret تصادفی نشست را در `.env` ذخیره می‌کند. فایل واقعی `.env` همراه بسته نیست و باید روی سرور ساخته شود.

اگر Node.js میزبان در دسترس نیست یا قدیمی است، همین مرحله با Docker انجام می‌شود:

```bash
docker run --rm -it --user "$(id -u):$(id -g)" \
  -v "$PWD:/app" -w /app node:26.13.1-bookworm-slim \
  node tools/setup.mjs
```

۳. اجرا و بررسی سلامت:

```bash
docker compose up -d --build
docker compose ps
curl -fsS http://127.0.0.1:7480/healthz
```

خروجی سلامت: `{"status":"ok","storage":"sqlite"}`.

در حالت بدون پیشوند، فرم در `/` و مدیریت در `/admin` قرار دارند. پورت میزبان به‌صورت پیش‌فرض فقط روی loopback باز است تا Nginx آن را در اختیار کاربران قرار دهد.

## قرارگرفتن کنار اسکیل‌آپ روی همان دامنه

برای ارائهٔ فرم در مسیر `/heyat/` و مدیریت در `/heyat/admin`، این مقدارها را در `.env` تنظیم کنید:

```env
BASE_PATH=/heyat
PUBLIC_BASE_URL=https://skill-up.ir
COOKIE_SECURE=true
TRUST_PROXY=true
```

سپس کانتینر را دوباره اجرا کنید:

```bash
docker compose up -d --build
curl -fsS http://127.0.0.1:7480/heyat/healthz
```

بلاک‌های `deploy/nginx-heyat-location.conf` داخل بلوک HTTPS موجود اسکیل‌آپ قرار می‌گیرند. این تنظیم درخواست‌های `/heyat/` را به پورت `7480` می‌فرستد. اگر پورت Docker را تغییر دادید، مقدار `proxy_pass` را هم هماهنگ کنید.

پس از افزودن تنظیم:

```bash
sudo nginx -t
sudo systemctl reload nginx
```

فرم: `https://skill-up.ir/heyat/`

مدیریت: `https://skill-up.ir/heyat/admin`

این نشانی‌ها **پس از نصب و تنظیم Nginx توسط برنامه‌نویس** در دسترس خواهند بود؛ این بسته به‌خودی‌خود روی سرور نصب نشده است.

برای دامنهٔ اختصاصی دیگر، `BASE_PATH` را خالی و `PUBLIC_BASE_URL` را مبدأ HTTPS همان دامنه قرار دهید. reverse proxy باید `X-Forwarded-For` را با IP واقعی درخواست جایگزین کند؛ فایل نمونه همین کار را انجام می‌دهد. `TRUST_PROXY` فقط برای اجرای پشت چنین پراکسی‌ای فعال می‌شود.

## پنل مدیریت و فایل اکسل

- ورود با نام کاربری و رمز تعیین‌شده در setup. برای تنظیمات نسخهٔ قبلی، نام کاربری پیش‌فرض `admin` است. نشست مدیر هشت ساعت اعتبار دارد.
- تعداد کل پاسخ‌ها، پاسخ‌های امروز، نظرهای متنی و درصد رضایت کلی.
- نمودار توزیع رضایت هر بخش، میزان حضور، تناسب ساعت و مدت و اولویت‌های بهبود.
- جست‌وجو بر اساس نام، شماره، شناسه یا متن نظر؛ نمایش صفحه‌بندی‌شده و جزئیات تمام سؤال‌ها.
- خروجی `.xlsx` شامل پنج برگه: «پاسخ‌ها»، «امتیازها»، «خلاصه»، «اولویت‌ها» و «توزیع پاسخ‌ها».

دکمهٔ دریافت اکسل، **تمام ردیف‌های دیتابیس** را صادر می‌کند و به صفحه‌بندی یا جست‌وجوی پنل محدود نیست. برگهٔ «پاسخ‌ها» ۲۰ ستون شامل شناسه، دو زمان ثبت، نام، شماره، هر ۱۳ پرسش، اولویت‌ها و نظر آزاد دارد؛ فهرست ستون‌ها در `HANDOFF.md` آمده است.

نام و شماره فقط در بخش خصوصی پاسخ‌ها و برگهٔ پاسخ‌های کامل قرار می‌گیرند. نمودارها و برگه‌های آماری مشخصات تماس ندارند. شماره در Excel از نوع متن است و صفر ابتدای آن حفظ می‌شود. متن‌های کاربر به‌صورت متن ذخیره می‌شوند و فرمول Excel نمی‌شوند.

رضایت فقط برای گزینه‌های ۱ تا ۵ محاسبه می‌شود. گزینهٔ خنثی امتیاز ۳ دارد. «تجربه نکردم»، «امکان ارزیابی ندارم» و سؤال بی‌پاسخ وضعیت‌های جدا دارند و وارد میانگین نمی‌شوند. در سؤال‌های ساعت، مدت و تعداد، «مناسب» گزینهٔ مطلوب است و این پاسخ‌ها با امتیاز رضایت جمع نمی‌شوند. پاسخ فرد غایب وارد ارزیابی بخش‌های مراسم نمی‌شود.

## ماندگاری و نسخهٔ پشتیبان

پاسخ‌ها در فایل `/app/data/survey.sqlite` و volume اختصاصی `heyat-survey_survey_data` ذخیره می‌شوند. فرم پس از ثبت در همین دیتابیس پیام موفقیت نشان می‌دهد. پنل و Excel نیز از همین محل واحد می‌خوانند. بازسازی تصویر و راه‌اندازی دوبارهٔ کانتینر این volume را حفظ می‌کند. اجرای `docker compose down -v` باعث حذف volumeها و داده‌ها می‌شود و برای به‌روزرسانی عادی استفاده نمی‌شود.

پشتیبان سازگار با SQLite در حال اجرا:

```bash
docker compose exec -T survey node tools/backup.mjs
mkdir -p backups
docker compose cp survey:/app/backups/. ./backups/
```

فایل پشتیبان یک دیتابیس مستقل و کامل است و داده‌های موجود در WAL را هم در بر می‌گیرد. مسیر پشتیبان‌ها داخل کانتینر در volume جداگانه ماندگار است.

بازگردانی را برنامه‌نویس پس از توقف همین کانتینر و تهیهٔ پشتیبان از وضعیت فعلی انجام دهد: snapshot را جایگزین `survey.sqlite` در volume داده کند و فایل‌های WAL/SHM قدیمی همان دیتابیس را در حالت متوقف کنار بگذارد. فایل `.env` و پشتیبان‌ها خصوصی نگه داشته شوند.

## تغییر رمز مدیریت

در پوشهٔ پروژه:

```bash
npm run setup -- --reset-admin
docker compose up -d --force-recreate
```

این کار پاسخ‌های نظرسنجی را تغییر نمی‌دهد و پس از راه‌اندازی دوباره، نشست‌های قبلی مدیریت اعتبار نخواهند داشت.

## اجرا بدون Docker

پیش‌نیاز: Node.js نسخهٔ `22.13` یا بالاتر؛ نسخهٔ LTS پشتیبانی‌شده مناسب است.

```bash
npm run setup
npm start
```

پورت پیش‌فرض `3000` و مسیر داده `./data` است. تنظیمات از `.env` خوانده می‌شوند. برای پشتیبان:

```bash
npm run backup
```

## آزمون و ساخت بسته

```bash
npm run check
npm test
npm run package
```

تست‌ها دیتابیس مستقل در `qa/` می‌سازند و به دادهٔ اصلی متصل نمی‌شوند. بستهٔ نهایی در `release/heyat-survey-final.zip` ساخته می‌شود و فایل‌های واقعی `.env`، دیتابیس، پشتیبان، اطلاعات Git و داده‌های آزمایشی را شامل نمی‌شود.

شرح بررسی‌ها و محدودیت تأیید Docker در `TESTING.md` آمده است.

برای بررسی مستقل فایل اکسل تولیدشده در تست‌ها، در محیط توسعهٔ دارای Python و openpyxl، پس از `npm test` دستور `python test/verify-export.py` را اجرا کنید. Python برای اجرای خود برنامه لازم نیست.

## ساختار

- `dist/`: فرم، پنل مدیریت، CSS، فونت‌های محلی و تعریف مشترک سؤال‌ها.
- `server.mjs` و `lib/`: HTTP، اعتبارسنجی، SQLite، نشست مدیر، آمار و ساخت XLSX.
- `Dockerfile` و `compose.yaml`: اجرا با کانتینر مستقل و volume ماندگار.
- `deploy/`: تنظیم Nginx برای مسیر `/heyat/`.
- `tools/`: ساخت تنظیمات، پشتیبان، کنترل کد و بسته‌بندی.
- `test/`: آزمون‌های یکپارچهٔ بک‌اند و حفاظت از داده‌ها.

فونت‌ها: [وزیرمتن](https://github.com/rastikerdar/vazirmatn)، [امیری](https://github.com/aliftype/amiri). مجوزهای OFL همراه فونت‌ها در `dist/assets/fonts` قرار دارند. لوگوی طلایی هیئت در `dist/assets/heyat-logo-gold.png` قرار دارد؛ مشخصات و دستور بازسازی آن در `LOGO-NOTES.md` آمده است. لوگو، فونت‌ها و خطوط اسلیمی همگی محلی هستند و فرم به CDN خارجی وابسته نیست.
