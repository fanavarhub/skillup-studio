# نصب و به‌روزرسانی اسکیل‌آپ روی Ubuntu

مسئول DevOps این دستورات را روی سرور اجرا کند. دسترسی sudo و دسترسی خواندن مخزن خصوصی با حساب یا کلید GitHub خود مسئول DevOps لازم است.

## نصب روی سرور تازه

پیش از اجرا، رکورد DNS دامنهٔ skill-up.ir را روی IP عمومی سرور تنظیم کنید. اگر www را فعال می‌کنید، DNS آن را نیز تنظیم کنید. پورت‌های TCP 80 و 443 باید در فایروال سرور و ارائه‌دهندهٔ VPS باز باشند. پورت داخلی 4050 فقط روی loopback است.

پس از ادغام نسخهٔ دیدگاه‌های مقاله‌ها در شاخهٔ `main`، مخزن را کلون کنید.

    git clone --branch main https://github.com/fanavarhub/skillup-studio.git
    cd skillup-studio
    sudo bash deploy/install-ubuntu.sh

برای clone به عنوان کاربر عادی وارد GitHub شوید و sudo را فقط برای اجرای اسکریپت به کار ببرید.

اسکریپت دامنه، فعال‌سازی www، ایمیل Let's Encrypt، پذیرش شرایط گواهی، نام کاربری و رمز مدیر، شناسه دورهٔ رایگان و تنظیمات اختیاری GA4 و Search Console را می‌پرسد. رمز مدیر هنگام تایپ روی صفحه نمایش داده نمی‌شود. کلید نشست به‌صورت تصادفی ساخته و در فایل محلی .env با مجوز 0600 ذخیره می‌شود. آدرس دامنهٔ فعلی در بخش‌هایی از برنامه ثابت است. برای انتقال به دامنه‌ای دیگر، ابتدا آدرس‌های canonical برنامه را تغییر دهید.

اسکریپت Docker و Compose را در صورت نیاز نصب می‌کند، سرویس را می‌سازد، Nginx و گواهی HTTPS را تنظیم می‌کند و سلامت سرویس و دسترسی به مقاله را بررسی می‌کند. اگر vhost همین دامنه از قبل وجود داشته باشد، مسیر نصب تازه متوقف می‌شود تا پیکربندی موجود جایگزین نشود.

## به‌روزرسانی سرور فعلی

بعد از ادغام Pull Request، در همان پوشه‌ای که کانتینر فعلی از آن اجرا شده است:

    cd "$(sudo docker inspect --format '{{index .Config.Labels "com.docker.compose.project.working_dir"}}' skillup-studio)"
    git switch main
    git pull --ff-only origin main
    sudo bash deploy/install-ubuntu.sh --update

دیدگاه‌های مقاله‌ها از همان حساب اصلی سایت و پنل `/admin` استفاده می‌کنند. برای این نسخه دیگر تنظیم `SCRATCH_LESSON_ADMIN_TOKEN` و `SCRATCH_LESSON_TRUST_PROXY` لازم نیست؛ اگر در `.env` قدیمی مانده‌اند، روی سرویس جدید اثری ندارند. اگر سرور پوشه‌ای متفاوت با کانتینر فعال دارد، نصب را از همان پوشهٔ کانتینر انجام دهید.

در حالت update اسکریپت از دیتابیس‌های SQLite پشتیبان آنلاین می‌گیرد و محل پشتیبان را چاپ می‌کند. دیدگاه‌های تأییدشدهٔ قدیمی درس ۱۱ فقط یک بار از دیتابیس قدیمی به دیتابیس اصلی منتقل می‌شوند؛ این کار با هر راه‌اندازی مجدد تکراری ایجاد نمی‌کند. فایل‌های آپلودشده در پوشهٔ data می‌مانند. برای مهاجرت به VPS دیگر، پوشهٔ data و فایل .env هم باید طبق روال انتقال و پشتیبان‌گیری تیم منتقل شوند.

## بررسی و نگهداری

    sudo docker compose ps
    sudo docker compose logs --tail=100 skillup
    sudo nginx -t
    sudo certbot renew --dry-run
    curl -fsS https://skill-up.ir/api/health
    curl -fsSI https://skill-up.ir/magazine/scratch-costume-animation
    curl -fsS https://skill-up.ir/api/magazine/scratch-costume-animation/comments

برای بررسی عملکرد، یک حساب هنرجوی آزمایشی در سایت وارد شود و یک دیدگاه در مقاله ثبت کند. دیدگاه باید همان لحظه نمایش داده شود. مدیر در `/admin` به تب «دیدگاه‌های مقاله‌ها» برود، مقاله را انتخاب کند و پاسخ، حذف و پین را بررسی کند. صفحهٔ عمومی بدون ورود قابل خواندن است، ولی ثبت دیدگاه و پاسخ به ورود نیاز دارد.
