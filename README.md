# Skill Up Studio

نسخه اصلی پلتفرم آموزشی اسکیل آپ برای هنرجویان ۸ تا ۱۷ سال. رابط کاربری با React، API با Express و ذخیره‌سازی با SQLite پیاده شده است.

## ساختار پروژه

- `src/components/`: صفحه اصلی، دوره‌ها، گالری پروژه، پنل هنرجو و پنل مدیر.
- `server.ts`: سرور اصلی، مسیرهای قدیمی سازگار و سرو فایل‌های production.
- `platform.ts`: مدل امن پلتفرم آموزشی؛ XP، لیگ، پروژه، Rubric، اعلان، باشگاه، گواهینامه و گزارش مدیر.
- `learning.ts`: دوره/جلسه، آپلود امن فایل، لینک امضاشده، پیشرفت خودکار و نظرهای سایت.
- `auth.ts`: نشست‌های امضاشده و کنترل دسترسی مدیر/هنرجو.
- `src/data.ts`: داده اولیه دوره‌ها و نمونه‌پروژه‌ها.
- `public/`: تصویرها، فایل‌های عمومی، `robots.txt` و `sitemap.xml`.
- `tests/`: تست یکپارچه امنیت و گردش‌های اصلی API.
- `data/`: دیتابیس و فایل‌های آپلودشده ماندگار؛ در Git قرار نمی‌گیرد.

## قابلیت‌های آموزشی

- Level نامحدود با فرمول `20 + level × 5` برای سطح بعد.
- دفترکل XP و جلوگیری از ثبت تکراری امتیاز.
- ساخت دوره و جلسه از پنل مدیر، تعیین امتیاز هر جلسه و آپلود ویدئو، PDF، ZIP، تصویر و Excel.
- تکمیل خودکار جلسه پس از مشاهده واقعی ۷۵٪ ویدئو؛ بازه‌های دیده‌شده ذخیره می‌شوند و جلو زدن یا تکرار یک بخش امتیاز اضافه نمی‌سازد.
- ارسال پروژه با ۴۰ XP و Rubric مدیر تا ۶۰ XP؛ چرخه «نیازمند اصلاح → ارسال مجدد → تأیید».
- لیگ هفتگی شنبه تا جمعه فقط برای هنرجوهای واقعی؛ حساب‌های آزمایشی صرفاً در گزارش پنل مدیر هستند.
- اعلان خودکار توقف یادگیری، ویدئوی نیمه‌تمام و پروژه عقب‌افتاده.
- باشگاه عمومی، پرسش‌وپاسخ و پروژه‌ها با اعلان مدیر.
- Skill Passport، درخواست گواهینامه، تأیید مدیر، QR و صفحه اعتبارسنجی عمومی.
- آزمون تعیین مسیر و ثبت جلسه آزمایشی رایگان.
- داشبورد آموزشی مدیر شامل زمان مشاهده، پاسخ‌ها، پروژه‌ها، فعالیت حساب نمایشی و خروجی CSV سازگار با Excel.
- گردش بررسی نظرها: در انتظار، تأیید/رد، پاسخ مدیر، انتخاب نظر ویژه و نمایش در صفحه اصلی.
- فونت Vazirmatn از خود سرور ارائه می‌شود و برای نمایش اولیه به سرویس فونت خارجی وابسته نیست.

## اجرای محلی

پیش‌نیاز: Node.js 24 یا جدیدتر، چون پروژه از `node:sqlite` استفاده می‌کند.

```bash
npm ci
npm run dev
```

آدرس پیش‌فرض: `http://localhost:3000`

## تنظیمات محیطی production

فایل `.env.example` را به `.env` کپی و مقدارهای زیر را با مقدار واقعی جایگزین کنید:

- `SKILLUP_ADMIN_USERNAME`: نام کاربری مدیر (پیش‌فرض `admin`).
- `SKILLUP_ADMIN_PASSWORD`: رمز طولانی و یکتای مدیر.
- `SKILLUP_SESSION_SECRET`: مقدار تصادفی حداقل ۳۲ کاراکتر برای امضای نشست‌ها.
- `PUBLIC_BASE_URL`: دامنه عمومی برای لینک QR گواهینامه.

هیچ رمز یا کلید واقعی نباید commit شود.

## کنترل کیفیت

```bash
npm run lint
npm test
npm audit
```

`npm test` ابتدا نسخه production را می‌سازد و سپس روی یک دیتابیس موقت، ورود امن، جداسازی کاربر، XP، پروژه، لیگ، داشبورد مدیر، گواهینامه و QR را آزمایش می‌کند.

## استقرار با Docker

```bash
docker compose up -d --build
```

دیتابیس در `./data` ماندگار می‌شود. پیش از استقرار از همین پوشه نسخه پشتیبان بگیرید. فایل دیتابیس و `.env` نباید به GitHub بروند.

اگر Nginx جلوی برنامه است، برای آپلود ویدئو این تنظیم‌ها را در بلاک دامنه قرار دهید و سپس Nginx را reload کنید:

```nginx
client_max_body_size 500M;
proxy_read_timeout 600s;
proxy_send_timeout 600s;
```

## به‌روزرسانی سرور پس از merge در main

```bash
cd ~/public/skillup
git fetch origin
git checkout main
git pull --ff-only origin main
npm ci
npm run lint
npm test
npm run build
```

سپس فقط روش اجرای فعلی سرور را restart کنید؛ برای نمونه یکی از این دو حالت:

```bash
pm2 restart skillup --update-env
```

یا:

```bash
docker compose up -d --build
```

قبل از هر استقرار از `data/` پشتیبان بگیرید. اجرای `npm run clean` روی سرور production ممنوع است، چون پوشه داده را پاک می‌کند.
